## 📋 发布前检查 (Pre-Release)

### 代码质量

- [ ] 所有代码已通过 code review
- [ ] 无未解决的 merge conflicts
- [ ] 所有 lint 检查通过 (`npm run lint`)
- [ ] 代码格式化已应用 (`npm run format`)
- [ ] 无 TypeScript 错误 (`tsc -b`)

### 测试

- [ ] 所有单元测试通过 (`npm run test`)
- [ ] 测试覆盖率 >= 80% (`npm run test:coverage`)
- [ ] 所有 E2E 测试通过 (`npm run e2e`)
- [ ] 手动测试核心功能
  - [ ] 用户认证流程
  - [ ] 项目创建和管理
  - [ ] 文件操作 (CRUD)
  - [ ] 任务执行和监控
  - [ ] WebSocket 实时通信
  - [ ] 模式切换和 Prompt 提交

### 依赖和安全

- [ ] 运行 `npm audit` 检查安全漏洞
- [ ] 所有高危漏洞已修复
- [ ] 依赖版本已更新到稳定版本
- [ ] 检查过期依赖 (`npm outdated`)

### 环境配置

- [ ] `.env.staging` 配置正确
- [ ] `.env.production` 配置正确
- [ ] 环境变量验证通过
- [ ] API 和 WebSocket 端点可访问

### 文档

- [ ] README.md 已更新
- [ ] CHANGELOG.md 已更新
- [ ] API 文档已同步
- [ ] 部署文档已更新 (`docs/deployment.md`)

### 构建验证

- [ ] Staging 构建成功 (`npm run build:staging`)
- [ ] Production 构建成功 (`npm run build:production`)
- [ ] Bundle 大小检查 (`npm run build:analyze`)
  - [ ] 总大小 < 2MB (gzipped)
  - [ ] 主 chunk < 500KB
  - [ ] Vendor chunks 合理拆分
- [ ] 构建产物无错误和警告

### Docker

- [ ] Docker 镜像构建成功
- [ ] Docker 容器启动正常
- [ ] 健康检查通过
- [ ] 容器日志无错误

## 🚨 回滚检查清单

### 触发条件

在以下情况需要考虑回滚:

- [ ] 应用无法启动或访问
- [ ] 关键功能完全失效
- [ ] 数据丢失或损坏
- [ ] 严重性能问题
- [ ] 安全漏洞被利用

### 回滚步骤

1. **立即行动**
   - [ ] 通知团队准备回滚
   - [ ] 记录当前问题

2. **执行回滚**
   ```bash
   ./scripts/deploy.sh rollback -s example.com -t v{previous_version}
   ```
   - [ ] 回滚命令执行成功
   - [ ] 应用恢复正常访问

3. **验证**
   - [ ] 核心功能正常
   - [ ] 数据完整性检查
   - [ ] 用户可以正常使用

4. **后续处理**
   - [ ] 分析回滚原因
   - [ ] 修复问题
   - [ ] 准备新的发布

## 📊 性能基准

### 关键指标阈值

| 指标 | 目标 | 可接受 | 不可接受 |
|-----|------|--------|---------|
| LCP | < 2.0s | < 2.5s | >= 2.5s |
| FID | < 50ms | < 100ms | >= 100ms |
| CLS | < 0.05 | < 0.1 | >= 0.1 |
| Bundle Size (gzip) | < 1.5MB | < 2MB | >= 2MB |
| API 响应时间 | < 200ms | < 500ms | >= 500ms |

### 浏览器兼容性

- [ ] Chrome >= 100
- [ ] Firefox >= 100
- [ ] Safari >= 15
- [ ] Edge >= 100
